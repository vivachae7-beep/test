# 당기·전기 계정원장 비교분석

교육 발표용으로 제작한 Excel 기반 계정원장 비교분석 템플릿입니다.

## 주요 기능

- 당기 및 전기 계정원장을 계정코드 기준으로 통합 비교
- 전기에 없고 당기에 생긴 계정은 **신규**로 구분
- 전기에 있었지만 당기에 없어진 계정은 **소멸**로 구분
- 양 기간에 모두 존재하는 계정은 순액의 **금액변동** 계산
- 기본 중요성 기준: 절대 증감률 20% 이상이면서 절대 증감액 1억 원 이상
- 결의서명 키워드를 이용한 거래 원인의 1차 분류
- 결의서명만으로 판단하기 어려운 거래는 **붙임 문서 확인 필요**로 표시
- 대상 계정의 전기·당기 상세 거래 자동 추출
- 입력 누락과 미검토 건을 확인하는 점검 시트 제공

## 파일 구성

- `templates/당기_전기_계정원장_비교분석_템플릿.xlsx`: 완성된 Excel 템플릿
- `src/build_ledger_analysis.mjs`: 템플릿 생성 소스
- `.gitignore`: 실제 원장과 분석 결과가 공개 저장소에 올라가지 않도록 차단

## 사용 방법

1. Excel 템플릿을 내려받습니다.
2. `전기원장`과 `당기원장` 시트의 예시 행을 삭제합니다.
3. 각 원장의 A:G 열에 계정코드, 계정명, 전표일자, 결의서번호, 결의서명, 차변, 대변을 붙여 넣습니다.
4. `계정비교` 시트에서 신규·소멸·금액변동과 원인분석 대상을 확인합니다.
5. `세부원인분석` 시트에서 거래별 1차 원인분류와 붙임 확인 여부를 검토합니다.
6. 인트라넷 문서에 접근할 수 없는 건은 추측하지 않고 `붙임 문서 검토 필요` 상태로 남깁니다.

> 동적 배열 함수(LET, FILTER, VSTACK, HSTACK, UNIQUE 등)를 사용하므로 Microsoft 365 또는 이를 지원하는 최신 Excel 사용을 권장합니다.

## 분석 기준

기본 증감률은 `|당기-전기| ÷ |전기|`입니다.

- 신규: 전기 순액 0, 당기 순액 존재
- 소멸: 전기 순액 존재, 당기 순액 0
- 금액변동: 전기·당기 모두 순액 존재
- 변동없음: 전기와 당기 순액 동일

신규와 소멸은 증감률 대신 유형으로 판정하며, 절대 증감액이 기준 이상이면 원인분석 대상이 됩니다.
