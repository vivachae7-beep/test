# 선급금 결산 Review Agent — UI prototype

현재 단계는 UI 프로토타입입니다.

- 대시보드와 4단계 업무 흐름
- 선급금 계정원장 업로드 영역
- 기준 매핑표 연결 상태
- 반응형 레이아웃
- 결산조정대체전표 미리보기
- Excel/MD 다운로드
- 익년 1월 1일 환원전표 초안
- 계속사업 여부 및 사업ID 적용
- 신규 검토결과 양식: `(TEST1) 선급금 계정_검토결과 양식.xlsx`
- 교체된 조정전표 양식: `결산조정대체전표_선급금_V2.xls`

기준자료 변경:
- 기존 결산조정전표 양식은 V2 파일로 교체했습니다.
- `(TEST1) 선급금 계정_검토결과 양식.xlsx`는 검토결과용 신규 양식으로 추가했습니다.
- 두 파일은 `templates/` 폴더에 보관되어 있습니다.

아직 구현하지 않은 기능: 실제 이메일 발송, 기관 시스템 업로드, 서버 저장, 기관별 최종 차변·대변 계정 검증, 신규 V2 양식의 모든 46개 컬럼 자동 입력.
